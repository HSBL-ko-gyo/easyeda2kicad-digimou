# Security policy

Do not put security vulnerabilities, API keys, client secrets, access tokens,
Authorization headers, credential-bearing URLs, or raw cache archives in a
public issue.

Use GitHub private vulnerability reporting:

<https://github.com/HSBL-ko-gyo/easyeda2kicad-digimou/security/advisories/new>

If GitHub does not show the private reporting form, open a public issue that
contains no vulnerability details or secrets and asks the maintainer to provide
a private contact route. Wait for that route before sharing technical details.

When reporting privately, include only the minimum sanitized reproduction.
Credential rotation remains the reporter's responsibility if a real credential
was exposed before sanitization.
