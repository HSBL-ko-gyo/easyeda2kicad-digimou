# easyeda2kicad +DigiMou 1.1.0b1 Beta

This is the first public beta of an unofficial derivative of
[uPesy/easyeda2kicad.py](https://github.com/uPesy/easyeda2kicad.py), based on
upstream commit `fff10a38619963d7cb1c57d779655a9ea4572e95`. The complete work
remains licensed under GNU AGPL-3.0. It is not an official DigiKey, Mouser,
LCSC, EasyEDA, or upstream release.

## What is included

- The existing `easyeda2kicad` import package, CLI command, public Python API,
  legacy `--lcsc_id` path, and legacy KiCad output remain in place.
- Exact-MPN, fail-closed metadata resolution for LCSC, DigiKey, and Mouser.
- JSON and CSV Manifests with deterministic provenance and diagnostics.
- Credential-safe raw and normalized metadata cache with offline and refresh
  modes.
- Stable native Manufacturer/MPN/LCSC/Datasheet projection into KiCad.
  Provider-specific and volatile sales metadata, including price and stock,
  remains Manifest-only.
- Typed `CAD_NOT_FOUND` handling and optional `--require-cad` failure.

## Field-table and real-service evidence

Unauthenticated LCSC/EasyEDA end-to-end conversion passed for:

- OPA333AIDBVR / C30878
- LM321MF/NOPB / C131103

For both parts, legacy and metadata modes produced byte-identical symbol and
footprint artifacts in equivalent path contexts. Metadata added zero new
property keys, Provider/volatile fields stayed Manifest-only, and a repeated
metadata overwrite remained byte-identical with one root symbol.

## Beta feedback requested

The following are accepted beta risks rather than known release failures:

- DigiKey live API E2E with real credentials was not run.
- Mouser live API E2E with real credentials was not run.
- Native Linux process-level E2E was not run.
- 69 inherited upstream reference-output tests are skipped because the optional
  external reference bundle is absent.

Please report real-environment results using the bug template. Never attach API
keys, secrets, access tokens, Authorization headers, credential-bearing URLs,
or an unsanitized cache. Use the private reporting route in `SECURITY.md` for
security issues.

## Installation

Download the wheel from this GitHub pre-release and install it directly:

```text
python -m pip install ./easyeda2kicad-1.1.0b1-py3-none-any.whl
```

This beta is not published to PyPI. The distribution/import/CLI name remains
`easyeda2kicad`; the public display name is `easyeda2kicad +DigiMou`.

Verify downloaded files against `SHA256SUMS.txt` attached to the release.
