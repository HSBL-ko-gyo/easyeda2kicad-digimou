# easyeda2kicad +DigiMou 1.1.0b2 Beta

This is the second public beta of an unofficial derivative of
[uPesy/easyeda2kicad.py](https://github.com/uPesy/easyeda2kicad.py). The
complete work remains licensed under GNU AGPL-3.0. It is not an official
DigiKey, Mouser, LCSC, EasyEDA, Ultra Librarian, SamacSys, or upstream release.

The release assets were rebuilt on 2026-07-30 to add product-specific DigiKey
CAD-source discovery. Checksums from the earlier `1.1.0b2` upload do not apply
to the replacement assets; verify downloads against the attached
`SHA256SUMS.txt`.

## Important installation identity change

This beta fixes the install-time collision present in `1.1.0b1`.

| Surface | `1.1.0b2` identity |
| --- | --- |
| Distribution / wheel | `easyeda2kicad-digimou` |
| Primary command | `easyeda2kicad-digimou` |
| Python package | `easyeda2kicad_digimou` |
| Module invocation | `python -m easyeda2kicad_digimou` |

The wheel no longer installs the upstream `easyeda2kicad` Python package or
console command. Upstream and +DigiMou can now be installed and uninstalled
independently in the same environment. The legacy CLI arguments, default
generated library name/path, `${EASYEDA2KICAD}` variable, and KiCad output
format remain compatible.

A clean environment is recommended when moving from `1.1.0b1`, because that
older beta used the upstream install identity. Do not blindly uninstall the
`easyeda2kicad` distribution from a shared environment without first checking
whether it is the old +DigiMou beta or the upstream project.

## What changed since 1.1.0b1

- Added explicit fail-closed CAD sources:
  `easyeda`, `digikey`, `mouser`, and deterministic `auto`.
- Added secure, identity-proven local intake for user-downloaded native KiCad
  Ultra Librarian and SamacSys packages, plus manufacturer-provided footprint
  and STEP/WRL partial packages.
- DigiKey now reports the actual product-specific manufacturer/provider links
  instead of treating DigiKey as an Ultra Librarian alias. Known linked
  providers remain separate, unknown hosts remain truthful manual handoffs,
  and available/missing artifact types are recorded in the manifest.
- A verified manufacturer footprint plus 3D package can be installed as
  `CAD_PARTIAL` with `SYMBOL_UNAVAILABLE`; no symbol is invented or silently
  substituted.
- Completed a real DigiKey/Ultra Librarian AD5314BRM path through authenticated
  exact discovery, manual official handoff, package import, project
  registration, KiCad CLI 7/9/10, and KiCad 10 GUI validation.
- Verified authenticated Same Sky `MJ-2523-SMT-TR` discovery against DigiKey:
  the manufacturer footprint and 3D source are identified correctly, the
  missing symbol is explicit, and Ultra Librarian is not falsely claimed.
- Added atomic, idempotent project-local `sym-lib-table` and `fp-lib-table`
  registration with `${KIPRJMOD}` paths, collision detection, dry-run, and
  rollback.
- Added same-command JLCPCB/LCSC exact resolution independently of metadata and
  CAD provider selection.
- Added credential-free capability reporting without DigiKey/Mouser page
  scraping.
- Added schema-v1 machine JSON, JSON event streams, read-only discovery
  commands, typed exit codes, portable artifact paths, and hash verification.
- Added protected, opt-in live-provider smoke infrastructure and secret-canary
  scanning.
- Rewrote the README around verified workflows and explicit provider
  limitations.

## Known incomplete Mouser path

Mouser is deliberately not counted as complete in this beta:

- official Search API V2 exact lookup and sanitized Product Detail handoff are
  implemented;
- SamacSys package intake has deterministic fixture coverage;
- no credentialed real FM220A-W package import, project registration, KiCad
  CLI, or GUI proof has completed;
- the protected live workflow has no owner-provided `MOUSER_API_KEY` success.

Issues #7 and #8 remain open. Explicit `--cad-source mouser` never falls back to
EasyEDA, and this release must not be described as complete Mouser CAD support.

## Installation

Download the wheel from this GitHub pre-release and verify it against
`SHA256SUMS.txt`:

```text
python -m pip install ./easyeda2kicad_digimou-1.1.0b2-py3-none-any.whl
easyeda2kicad-digimou --version
```

This beta is not published to PyPI.

## Validation summary

- Full deterministic Python suite, Ruff lint/format, strict mypy, build, and
  Twine checks pass.
- The built wheel contains only `easyeda2kicad_digimou`, exposes only the
  `easyeda2kicad-digimou` command, and contains all three JSON schemas.
- Both installation orders with the upstream wheel pass. Uninstalling either
  distribution leaves the other package and command working.
- Legacy C2040 generated symbol/footprint goldens and existing exit behavior
  remain unchanged.
- Real DigiKey/Ultra Librarian KiCad CLI/GUI evidence is retained, and the Same
  Sky manufacturer-source discovery passes the live service; real Mouser
  evidence remains explicitly outstanding.

Never attach credentials, tokens, cookies, Authorization headers, private raw
responses, secret-bearing URLs, or provider packages to a public issue.
