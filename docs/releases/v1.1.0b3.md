# easyeda2kicad +DigiMou 1.1.0b3 Beta

This is the third public beta of an unofficial derivative of
[uPesy/easyeda2kicad.py](https://github.com/uPesy/easyeda2kicad.py). The
complete work remains licensed under GNU AGPL-3.0. It is not an official
DigiKey, Mouser, LCSC, EasyEDA, Ultra Librarian, SamacSys, or upstream release.

## What changed since 1.1.0b2

- Added a default-branch README consistency monitor. It checks introduced or
  removed public CLI options and conservatively flags production Python/schema
  changes that have no README review update. Its bounded public issue contains
  safe option names and counts, not raw commit subjects or repository paths.
- Extended existing `--cad-source auto` behavior at the artifact level. A
  missing or invalid EasyEDA symbol/footprint, pin/pad mismatch, or missing
  requested 3D model can continue to product-specific DigiKey and Mouser CAD
  discovery even when those distributors were not selected for metadata.
- Kept source selection fail-closed. External providers are considered only
  when one product-specific handoff advertises every missing artifact kind;
  artifact kinds cannot be combined across separate packages. Interactive
  login, agreement, request, or download steps remain manual.
- Added actionable human guidance for missing or rejected DigiKey and Mouser
  API credentials. The CLI names the exact environment variables, explains
  that API results require valid credentials, and prints the official setup
  URL without prompting for, echoing, or persisting secrets.
- Refreshed README examples and clarified that a Mouser Product Detail handoff
  does not prove SamacSys or any other delivery partner/model creator. Package
  provenance is recorded only after separate source and format validation.
- Applied configured-secret redaction to every human CLI log handler as well as
  machine output, manifests, and existing credential-safe storage boundaries.

No new command-line option was added in this beta.

## Installation

Download the wheel from this GitHub pre-release and verify it against
`SHA256SUMS.txt`:

```text
python -m pip install ./easyeda2kicad_digimou-1.1.0b3-py3-none-any.whl
easyeda2kicad-digimou --version
```

The distribution, command, and Python package remain
`easyeda2kicad-digimou`, `easyeda2kicad-digimou`, and
`easyeda2kicad_digimou`. This beta is not published to PyPI.

## Known limitations

- DigiKey and Mouser metadata require credentials issued to the user by the
  respective provider.
- Provider website search, login, agreement acceptance, package requests, and
  downloads are not automated.
- A real Mouser-linked package has not completed the project-registration,
  KiCad CLI, and KiCad GUI validation path. Complete Mouser CAD support is not
  claimed.
- Native Linux process E2E and the inherited upstream reference-output bundle
  remain outside the available release evidence.
